AI幻觉（Hallucination）

稳定 建条 2026-11-16 下次复核 2027-11-16

一句话说清楚

模型不是故意编。它每一步都必须挑一个「最可能的下一个 token」；不知道时也照挑，于是给出一个自信的猜测。

这条把「AI 胡说」从道德判断拉回生成机制：先看它怎么挑 token，再看这次是尖还是平，最后才是六个修法。

不是撒谎：它没有「跳过」这个选项

答案听起来正确、语气自信，但事实错误或纯属虚构——这就是幻觉。

典型例子：问一个冷门作者的出生年，模型没读过她的资料，却回答「1962 年」。它不是撒谎，是没有「跳过」这个选项。

先看清 token 是什么

模型不按「字 / 词」读写，而是把文本切成一小段一小段（token）：Meera 可能被切成 Me + era，1962 可能被切成 19 + 62。模型一个字一个字地往外蹦，蹦的就是 token。

所以每一步，它只做一件事：在词表里挑下一个最可能出现的 token。「这句话是否属实」不在这个动作里。

五步循环：每一步只问「最可能」

把一次回答拆开，就是一个循环，五步：

手机上左右滑动，看完整五步

关键：这个循环里没有「这一步是否属实」的检查，只有「哪个 token 最可能出现」。

五步走完，只得到「最可能」，不得到「已核实」。这就是为什么一段话可以语法通顺、逻辑顺滑，却从第一个错 token 开始就建在沙子上。

判断尺：这次是尖，还是平？

模型不知道时也照挑，但概率分布的形状不一样。把候选 token 的概率画出来，就能看出这次是「知道」还是「在猜」。

尖锐猜测模型知道

一个 token 拿 90%+

爱因斯坦生于 1879（95%）→ 几乎每次都对

平坦猜测模型不知道

多个 token 各 12%—14%

某冷门作者生于 1962（14%）→ 每次都可能不同，但都写得很自信

一根柱独大＝尖；一排柱差不多高＝平。形状不同，语气可以一样自信。

看什么尖锐猜测平坦猜测
含义模型知道模型不知道
概率分布一个 token 拿 90%+多个 token 各 12%—14%
例子爱因斯坦生于 1879（95%）某冷门作者生于 1962（14%）
结果几乎每次都对每次都可能不同，但都写得很自信
类比：全班都读过爱因斯坦，问出生年大家齐喊 1879；问冷门作者，每个人喊一个不同年份——但每个人都很笃定。

压成一条判断路线

一问 · 事实型吗名字、数字、日期、引用，全是幻觉高发区。
二问 · 会复现吗同一问题再问一次，事实 token 反复变，就是在猜。
三问 · 能核对吗有原始资料就喂进去（RAG）；没有，就别把语气当证据。

三问里任何一问答「不确定」，就按猜测处理。

六因：为什么它一定会编

六条原因，根子是同一个动作：不知道也必须挑一个 token。不是模型坏了，是逐 token 生成这件事本身决定的。

1没有「跳过」选项

不知道也必须选一个 token；「我不知道」在训练里出现得少、得分也常更低。

2随机性

温度控制随机程度。平坦分布时，温度决定这次猜哪个——同一个问题问五次可能得到五个年份。

3token 不能撤回

橡皮擦不存在，选了「是的」就永远留在文本里，只能往后写。

4错误滚雪球

后面每个 token 都基于前面的错 token；「是的，3827 是质数，因为……」——语法和逻辑都通顺，前提是错的。

5合理组合出不存在的东西

常见作者名 + 常见年份 + 像真的期刊名，每个 token 都合理，合起来是一篇不存在的论文、一条假引用。

6最终文本藏起不确定性

95% 选出的 token 和 14% 选出的 token，在最终文本里长得一模一样；没有小字标着「这是猜的」。

六修：只能减少，不能消除

六个修法，方向不同，但都只降低概率，不清零。

1RAG 喂事实

把正确资料放进上下文，让平坦猜测变尖锐猜测。

2训练它说「我不知道」

让诚实的不知道比自信的错答得分更高（模型厂商层面）。

3看 token 概率

支持 logprobs 的工具能看到每个 token 的把握；事实 token 概率低＝可能在猜。

4同一问题多问几次

名字、数字、日期反复变，就是在猜。

5先想再答（CoT）

把关键判断拆成步骤，别让整段答案押在第一个不确定 token 上。

6事实任务用低温

减少随机跳跃——但低温只是「每次猜同一个」，不等于正确。

铁律：名字、数字、日期、引用是幻觉高发区，必须人工核对。语气自信不是证据。

三条边界：

  • 本文解释的是机制层原因，不覆盖训练数据污染、对齐目标偏差等数据 / 目标层原因。
  • 「看 logprobs」需要工具支持，普通聊天界面通常看不到。
  • 修法都是降低概率，不是清零；高风险场景仍要人拍板。

三条常见误解

误解温度设 0 就没有幻觉
实际只是每次都选最高概率；最高概率若只有 14%，仍然是猜。
误解模型在骗我
实际它没有「故意」的能力，只是在做下一个 token 预测。
误解换个更强的模型就好了
实际只要还是逐 token 生成，就仍有自信猜测的可能。

桑老哥适用

落到你的日常：铁柱给的答案，先分「查到的」和「推的」。

  • 铁柱给的人名、数字、日期、链接、引用，默认当「待核」；用验证阶梯的证据分级去查。
  • 重要结论让铁柱换一次上下文再答，两次事实 token 不一致＝在猜。
  • 让铁柱先列「哪些是查到的、哪些是推的」，和你「产出纪律三条」里的「已确认事实 / 待确认」同构。
  • 做资料类任务优先用 RAG：先把原文喂进去，再让它总结。

接到「产出纪律三条」：幻觉最怕混进第一栏

已确认事实 · 标依据 我的建议 · 供选择 待确认 · 谁补

查不到就写「未知 / 未获取 / 未验证」，不写「应该 / 大概 / 正常」。

小白说法 ↔ 专业术语

把这一页的术语翻回大白话：

小白说法专业术语
它在一本正经地胡说幻觉（Hallucination）
一次蹦一个字自回归逐 token 生成
它其实没把握平坦的概率分布
它特别有把握尖锐的概率分布
每次答案都不一样采样随机性 / 温度
它编了个假出处事实 token 组合出不存在实体
把资料先给它看RAG（检索增强生成）
让它先说思路再答思维链（CoT）
