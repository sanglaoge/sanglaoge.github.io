Harness（AI 脚手架）

稳定 建条 2026-08-11 更新 2026-08-24 下次复核 2026-11-18

一句话说清楚

Model + Harness = Agent。模型只是大脑，Harness 是大脑之外让 AI 真正把事干成的所有工程——循环怎么收敛、工具返回什么、状态存哪、跑偏怎么拽回来。

AI 长任务跑偏多半不是模型笨，是 Harness 不够。两个比喻把「为什么」说透：

马具 · 力量为什么可控

harness 本义马具、安全带，动词指「控制并利用某种力量」。马有力量但不可控，套上马具力量才能被人用——Harness 不是给模型加能力，是让已有能力变得可控可用。

轮班工程师 · 为什么需要交接

长任务是轮班工程师接力的项目，每班到岗都没有上一班的记忆。Harness 留交接班记录（进度文件 + git log）、留验收清单（干完一条翻一条）、每班先定位再动手——压缩会吃掉记忆，跨会话续命靠的是 Harness 不是模型。

来龙去脉：第一次给 Harness 量出分

行业等式 Model + Harness = Agent 里，左半边（模型）每次发布都有榜单，右半边（Harness）长期没有尺子。2026-08，AOE Tech Labs（Floatboat）用最便宜的 DeepSeek-V4-Flash 做底座跑自家 Harness，五项第三方基准全胜贵 57.1 倍的 Claude Opus 4.8。关键实验：同一个模型，接原厂 Harness 输，接 Floatboat Harness 赢——模型不变，变量只有 Harness。

Floatboat 实验

57.1 倍价差之下五项基准全胜

DeepSeek-V4-Flash + 自研 Harness，赢了贵 57.1 倍的 Claude Opus 4.8。报告：floatboat.ai

Composio 四套壳

成本差 2 倍以上同一个模型，只换壳

同一 DeepSeek V4 Flash 装进 4 套 Harness：质量基本不变，单任务成本差 2 倍多——每轮上下文少 3 倍、只暴露 4 个工具、历史噪声少。HLR 不只量质量，还量钱包。

六个「可」：把强模型变成稳定干活的系统

可连接

模型能连外部世界（文件/接口/数据）——MCP 协议

可执行

能调工具、做动作、产生真实影响——MCP-Skill-Hook三件套

可约束

守规矩、高风险不乱来——红黄绿灯 + 闸门 + CLAUDE.md

可观测

知道 AI 在干啥、干得怎么样——自改进循环的「评测监控同源」

可恢复

挂了能续上、能回滚到检查点——工作日记 hook + 跨会话恢复

可验证

产出能被独立验收、不被自评骗——图谱工程 验证器

六个「可」不是并列功能，是缺任何一个，「强模型」就变不成「稳定干活的系统」。

四层结构 × 长程规律

层解决什么对应死法
Runtime 运行时AI 能碰到什么（文件/权限/沙盒）任务要改 7 个文件却没读写权
Agent Loop 循环长程能否收敛（= 循环工程）跑着跑着忘了最初目标
Tools 工具返回结构清不清楚工具把失败报成空字符串，AI 自信做错决定
Infra 基础设施失败能不能被发现状态没存好，哪步坏了都不知道

关键：四层有一层是别人的（套壳），上限就是别人的上限。自研 vs 套壳不是「修得好不好」，是「能不能修」。

HLR 杠杆率（给 Harness 装尺子）：HLR = 换 Harness 的收益 ÷ 换模型的收益。HLR > 1 意思是同一笔预算，花在执行系统上比花在升级模型上更值。数据来自 Floatboat 自家基准，HLR 是新提指标（非行业标准），但分子分母全用第三方公开分数，可重算。

长任务为什么跑偏 + 真正的 Proactive

不是某步答错，是循环没收敛——越跑离交付标准越远。两个病根：

  1. 交付标准一开始没说清。真实工作的标准随中间产物才清晰——「语气对不对」「能不能直接交付」这些在第一句话里根本不存在。
  2. 微小偏差滚雪球。模型每轮有微小偏差，下一轮把偏差当前提，20 步后累积成方向性错误——每步都合理，合起来不是你要的。

这正好是 循环工程 讲的「循环不收敛」，Harness 的活就是按住它。

真正的 Proactive（颠覆认知）：多数人以为「主动 Agent」= 定时自动干活（触发器主动）。真主动是——你说个模糊目标（自己都没想清要啥），Agent 在长程任务里不断探索/观察/修正，主动帮你发现「自己真正要什么」，并把它做到。

四问诊断框架（贾克斯，2026-09-14 并入）

AI 没干好，先查四问缺了哪问，别急着骂模型——这是「六个可」的口语版诊断入口：

四问英文查什么
它知道吗Context材料给够没
它做得到吗Capability工具配了没
它看得见结果吗Evidence测试/结果跑给它看没
它知道啥时候算完吗Gates完成标准写死没
  • 道术之分：OpenWiki/Hook/多 Agent 全是「术」，四问才是「道」
  • 双保险：AGENTS.md 教流程（软）+ PreToolUse Hook 拦关键动作（硬，改代码前查 Spec 没有就拒绝）——光教不拦它可能跳过（同构：咱家 CLAUDE.md 教规矩 + 红黄绿灯拦动作）
  • 干完留三类资产：业务事实（查得到依据）/ 回归测试（错了能报警）/ 机器可判规则（AI 自己会查），下次任务不从零开始
不只是告诉 Agent 什么叫完成，而是让不满足条件的任务无法被当成完成。

Co-Evolving 印证（DAIR.AI 论文周报）：让 AI 整套照抄专家工作全轨迹反而降 4-30 分，只纠失败步骤、保留自己打法的才涨——抄壳子配置没用，缺的是自家四问的答案。

生态动态：DSH 四部曲与四种壳（2026-08 并入）

DeepSeek 开源 DeepSeek Harness（DSH），四篇文章连读成一条线：

篇增量
贾栾：DSH 是什么一切皆插件（模型适配器/工具/会话日志/主循环全可替换）；能调度 Claude Code/Codex；Developer Preview 别迁关键工作
从零开发 DSH 插件5 分钟跑通第一个插件；配置铁律：凡是两个部署可能想要不同的值，必须是配置字段；预构建产物分发 = 不跑陌生脚本
空格：build-your-harness两半论：工具给的内核 + 你自己搭的外围（文件/权限/记忆）；五层体检 34 项（安全 yolo 告警/冷启动 12878 token/21 个死 Skill/记忆死链/半年没 git）
lencx：Minke v0.2.0远程控制新姿势：传消息不传画面（手机=控制面，车间不动）；从接缝挂载不改内核；能碰电脑的默认关

三个跨篇认知：①一切皆插件被三度实证——好架构留接缝，不让人动承重墙；②两半论落地——桑老哥的 vault（CLAUDE.md/docs/memory）就是「懂你」的那一半，壳子随便换，vault 才是不可替换的；③控制面模式已在用——手机发链接给飞书 bot、活在 Mac 上干，就是「传消息不传画面」的日常版。

辨伪注脚：Codex Harness「突然开源」系伪新闻（模块早已开源，自媒体炒冷饭）——看到「XX 突然开源」先问一句：之前真是闭源的吗？

轻记：川处安万字入门增量（2026-09-16 并入）

  • 四大件口语版：上下文管理（管草稿纸）/ 工具调用（是手脚）/ Agent Loop（踩油门）/ 状态管理（仓库存档）——状态管理管「存下来」，上下文管理管「这次拿哪些给大脑看」
  • MCP 常驻吃约 20% 上下文窗口（作者实测「一点没夸张」），Skill 渐进式加载远低于此——「全挂腰上」vs「用哪个翻哪个抽屉」
  • 「套壳」是外行话的正面论证：同脑不同身能力差很远；身体干的活远不止换皮（与「四层有一层是别人的，上限就是别人的上限」同一条线）
  • 记忆翻车一手案例：作者告诉 Gemini「我是程序员」后被钉死在该人设，只能关记忆——长期记忆「如何更新」难点的活例子（接 AI记忆系统三层架构）

边界

  • Harness 不是 MCP 那种统一协议，是各家自研的工程层，暂无行业标准
  • 数据来自 Floatboat 自家基准 + HLR 是新提指标（非行业标准），但分子分母全用第三方公开分数，可重算
  • 短任务（一次问答）Harness 增益小（1.9%），这种场景升级模型更直接

桑老哥适用

  • 你做视频/写 Listing/做设计，AI 跑偏不是模型笨，是你（或工具）没搭好「拽回标准」的机制
  • 你其实已经在搭简易 Harness：CLAUDE.md 规则 = 长期工作约束；闸门系统 = 收敛机制；上下文工程三件套 = 管什么信息留窗口/压缩/丢；循环工程 = Loop 层
  • 区别只是 Floatboat 做到了工业级且量化了价值（HLR）；你搭的是个人级 Harness，原理一致
  • 与「执行贬值判断力升值」（AI与人的分工原则）同一条线：执行外包给 Agent，判断和管壳留在人手里
