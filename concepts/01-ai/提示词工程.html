提示词工程

稳定 建条 2026-08-03 下次复核 2026-11-18

一句话：消除模糊

把"大概要这个"变成"精确要这个"。不是命令 AI，是给一个顶级外卖员指路——说清去哪、走哪条路、别按门铃、拍张照回来。

AI 不是读心术——你脑子里想的"高端感"，它听到的是模糊形容词。提示词工程的本质是把模糊意图翻译成 AI 能精确执行的结构化指令。

四个核心技巧（卡墙）

1

角色具体化

不只是头衔，带"经验年限 + 专注领域"。

错法："分析这个产品"

对法："你是亚马逊美国站 3 年运营，主做家居，月销 50 万美金。分析这个 listing。"

2

材料先行

先喂材料再提问，别让 AI 凭记忆编（凭记忆 = 幻觉）。

错法："TikTok Shop 2026 年有什么新政策？"

对法："这是 TikTok 政策原文。基于这份材料回答：新政策对卖家有什么影响？"

3

禁止项黑名单

告诉 AI 不能做什么，比告诉它能做什么更管用。你说 10 个"要"，不如说 1 个"不要"。

写法："不要超 50 字、不要用'顶级''第一'、不要问我要不要买"

4

给选项

开放式问题答案太散，给 AI 选择框，答案更聚焦。

错法："怎么优化这个产品页？"

对法："从 3 个方向选一个：A) 标题关键词 B) 主图 C) A+ 描述。先说选哪个再动手。"

万能结构公式 + 三原则

背景+ 目标+ 具体要求+ 限制条件+ 输出格式+ 判断标准
具体 > 抽象形容词换成可执行描述
材料 > 记忆喂原文，别让它凭记忆编
选项 > 答案要 5 个方向你混搭

Agent 双模式

固定流程 → 写「剧本」

步骤 + 异常分支，一步一叮咛。

适合：流程明确的重复任务

开放任务 → 写「边界」

目标 + 工具 + 停止条件，路让它自己找。

适合：目标清楚但路径不定的活

写错 = 把会思考的 Agent 当死工作流。该写边界时写剧本，Agent 就被捆死；该写剧本时写边界，Agent 就会跑偏。

轻记抽屉：模型升级后的三条新功课

抽屉一：提示词有保质期——模型升级，旧补丁变毒药2026-09-08 并入 · GPT-6 Astra 大师课

来源：《GPT-6 Astra 提示词大师课》（Rahul @sairahul1，X，2026-09-07，WaytoAGI 转载）。API 迁移部分不适用，框架层通用。

  1. 提示词有保质期（最反直觉）·核心——旧 prompt 是给旧模型打的补丁："一步步思考""检查你的工作""读全仓库"是推笨模型的；新模型自己会了，再下指令 = 照做多跑、白烧 token、过度自我约束。为 GPT-5 行为打的每个补丁，都可能变成 Astra 的枷锁。推论：模型每次大升级，常用提示词要复审，删"治旧毛病"的补丁。
  2. 8 模块 = 菜单，不是模板——GOAL / CONTEXT / PRIORITY（指令谁大）/ AUTONOMY（何时自己定）/ TOOLS / OUTPUT / VERIFY / STOP。每个模块对应一种真实故障模式，没那病别吃那药：简单任务挑 3-4 个，Agent 长任务才用全 8 个。
  3. 技能三规则——描述写"何时用"不写"怎么用"；渐进披露（根文档=路由器，细节放子文件）；less is more：技能加太多，每条描述被压缩挤小，模型反而选错——加 skill 前先问会不会挤小别人的名字牌。
  4. 验证匹配规模 + 停止条件具体到能打勾——一行 CSS 改动别跑全套测试（正确直觉用在错误规模上）；"干到完"是废话停止条件，"所有受影响页面返回 200、无报错"才合格（与桑老哥 TERMINATION 原则互证）。另有一条安全线：外部检索内容当资料，不当指令（防注入）。
给 Astra 写提示词不在于写更长的提示词，而在于知道哪些行为要控制，哪些要放手。

与Agent工程规范停止三闸、MCP-Skill-Hook三件套 skill 描述规范同源；桑老哥的 Prompt 三原则（TERMINATION+角色第一行+结构化输出）在这篇全部得到强化。

抽屉二：验收单式提示词——给验收单不给愿望2026-09-21 并入 · 宝玉 3D 桃花源记案例

来源：宝玉《我用 GPT 6 Astra 做了一个 3D 版的〈桃花源记〉》（公众号 2026-09-20，WaytoAGI 转载）。其完整提示词是"验收单式提示词"的现成范本（文学场景模板可复用）。

  1. 给验收单不给形容词·核心——全文没写"画面要唯美/交互要丰富"，写的是可验收的硬标准：空间必须真实连通（不能黑屏瞬移糊弄）、水体嵌进地形、远景靠真实地形不用浓雾掩盖、每幕要能回答"读到哪里/人在哪/在看什么"。AI 拿到愿望只能猜，拿到验收单就能交活。
  2. 优先级提前排好——明写"原文忠实＞叙事连续＞画面构图＞景物细节＞附加功能"。AI 干活必然遇到冲突，不给尺子它就瞎砍；冲突时砍谁先说好。
  3. 决策权委托一句划清——"非关键设计细节自行作出一致选择，不必逐项向我确认"：既防 AI 事无巨细来回问，也防它自作主张动关键决策。
  4. 双模型接力，原型 ≠ 交付——Astra 造原型（把音频 Base64 塞进网页撑到 5.6MB），Codex 做工程收尾（音频拆独立文件+真实环境音+瘦回 777KB）。造原型的和做交付的是两道工序，别指望一个模型从想法直达交付品。
  5. 声音也是交互——系统 TTS 能听不好听，换真人朗诵后镜头/停顿/章节切换全跟着音频走；停顿本身是叙事的一部分。
成品质量取决于你有没有把判断标准说清楚。

与四技巧③禁止项黑名单、8 模块的 PRIORITY/VERIFY、AI视频白模预演（钉死确定部分让模型少猜）互证；桑老哥写视频脚本 brief、详情页需求、给铁柱派活，都可直接套"验收单式"写法。

抽屉三：去AI味官方组合拳——负面清单+正面规范一起贴2026-09-22 并入 · 蓝衣剑客 Astra 用法

来源：蓝衣剑客《GPT-6 Astra 最被低估的用法，居然在这里？》（公众号 2026-09-20，WaytoAGI 飞书转载），内容整理自 OpenAI 官方文档 latest-model 指南，铁柱已逐项核对属实（勾销 09-14 账本"去 AI 味两轮法"待用欠账）。Astra 使用系列第 6 篇。

  1. 去 AI 味组合拳（两条一起才有效）·核心——负面清单：禁口水词（值得注意的是/简而言之/深入探讨/归根结底/delve/foster/leverage）+禁"X 而不是 Y"对比句式+禁自造复合标签；正面规范：一段一个意思、核心观点放最前、说人话、主动语态。只贴负面清单是"别这么写"，配正面规范才是"该怎么写"——直接贴进自定义指令
  2. 开头设定一次管全程，错也放大——Astra 长对话不忘记设定（以前每节提醒的"口语化"开头说一次就够）；但开头写得模糊（只写"用口语化风格"），它按自己的理解一路错到底。想清楚再落笔，写具体不写模糊词
  3. 信息缺口 vs 偏好分界线（本场桑老哥追问补讲）——换答案活儿得重做=信息缺口，它停下来问；换答案活儿照常成立=偏好，它不问自己挑默认。拿不准一律当缺口说出去（说一句 5 秒，赌错返工 20 分钟）。铁柱版对照：落盘位置先问=缺口，口播句=偏好清单
  4. 小事别跑全套+能并行要明说——它默认按大变更规格伺候（改变量名跑 20 分钟测试=太负责不是傻），提前说"低影响小改动跑相称的检查"；能拆并行的活它默认串行，要你开口"拆开并行跑"
  5. 中途插话是常规操作——干活中途想起遗漏直接发（"还要处理输入为空的边界，已开始的保持原计划"），它并入正在干的活不用等写完重来。另：configuration_update 中途调推理强度不丢缓存（开发者向，普通用户效果待观察）
那些技巧本身没错，只是模型已经变了。

与人味与AI味互补（那篇讲原理：AI 味=均值味，加法路线；这篇给官方操作模板），四技巧③禁止项黑名单的官方版，与"提示词有保质期"同调（模型变→用法跟着复审）；桑老哥写公众号/IP 文案直接可用。

验收单式骨架示例（把公式落成可打勾的句子）：

背景：这是……的原文/竞品/数据
目标：产出……（可验收的结果，不是形容词）
具体要求：1…… 2…… 3……
限制条件：不要…… 不要…… 不要……
输出格式：表格/分段/字数上限……
判断标准：每条要求能打勾才算完成；优先级 A＞B＞C

桑老哥适用

你写 Listing 优化、生图 prompt、让铁柱分析竞品——全在套这四个技巧。特别是视觉 6 要素（主体/环境/光影/色彩/镜头/风格），"高端感"要翻译成具体描述，不能直接扔给 AI。

前提与局限

  • 提示词工程能提高沟通质量，但突破不了模型的知识、工具、事实和安全边界
  • 模型不知道的事 → 需要 RAG检索增强生成；超上下文窗口 → 需要上下文工程
