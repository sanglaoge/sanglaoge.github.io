AI视频 · 不用视频模型这一支

代码画视频三路线

稳定 建条 2026-09-29 下次复核 2027-01-20 10 篇来源 · 累计加厚 6 次

一句话说清楚

不用视频模型，让 Claude 写代码画每一帧——哪帧不对改哪帧，画面文字不乱码。

视频模型是让画家凭感觉一口气画一整段；代码画是写好程序规定每一帧。前者是抽卡，后者是定点修。

这是 AI 视频家族此前真正的空白：家族里全是"怎么给视频模型写提示语"，没有"不用视频模型"这条路线。

它是怎么长成现在这样的

这条词条不是一个来源写成的，是一个月里七次撞见叠出来的。看它的长成过程，比看结论更能说明这条路为什么成立。

2026-09-25

先有现象，才有解释

Opus 5.5 发布后，一批"好看得不寻常"的 AI 视频冒出来。张梦飞拆了 10 个案例，发现共性：这些视频不是视频模型生成的，是 Claude 写代码画出来的（p5.js / three.js / Remotion）。代表作"末日之歌"（开源模板）、"机器人逃出虚拟世界"（12 种画风 4—5 小时没用视频模型）、《咬了一口月亮》中秋短片。

同一作者第二次撞见：从画面质感进到版面规范

卡尔再写 6 条去掉新模型 AI 味的提示语——这次治的不是线条，是信息怎么摆（字号、配色、框、动效）。同一人二撞，遂并入本条。至此三层齐了：质感、版面、生产线。

原理：代码画视频 = 翻页书

视频模型

让画家凭感觉一口气画一整段

  • 概率生成：每次结果不一样
  • 不满意 → 重抽（成本按次算）
  • 画面写字 → 必乱码
  • 改一个细节 → 整段重来

代码画

写好程序规定每一帧

  • 确定性绘制：同一份代码每次渲染一模一样
  • 不满意 → 定点修（改那几行）
  • 画面写字 → 文字就是一个形状，画出来就是对的
  • 改一个细节 → 只改那一帧

它和 AI视频白模预演 是同一思想的两张脸——把能确定的钉死，让模型少猜：白模在空间上钉死（走位、机位），代码画在时间上钉死（每一帧）。

两个杀手锏

哪帧不对改哪帧

视频模型的改法是重抽，代码画的改法是定点修。0.0 秒下蹲、0.2 秒腾空、0.4 秒落地——连续播放成动画，每一帧都可编辑。

这是抽卡问题的另一种解法：那边教"抽得省"，这边是"不用抽"。

画面文字不乱码

视频模型画面写字必乱码，这是电商视频卖点字幕的长期痛点。代码画里文字就是一个形状，画出来就是对的。

对做产品视频的人来说，这一条自己就值回票价。

画看改循环（好看的关键）

光会画不够。好几位作者共同的规矩是：让它渲染出静帧，回头自己看，放大挑毛病。

流程：渲染截图 → 看图找问题（鸟脚悬空没踩到树枝）→ 改代码 → 重新渲染，有问题继续循环。

这是验证器思想的视频版——AI 说"画好了"不算数，渲染出来亲眼看到才算。目标契约与五个闸门 的"把'做完了'当不可信声明"是同根。

Opus 5.5 的进步：会自己渲染看图找问题，有些毛病人还没提它已经改了。

三条路线 + 一条延伸

路线一

2D

p5.js / Canvas / SVG / Remotion

上限比想象高——12 种画风做 4—5 小时，全程没用视频模型。很多作品本身就是网页。

适合：风格化短片、片头动画。最合算的起步路线。

路线二

3D

three.js

先搭片场，再扛摄像机进去拍。提示词要把毛病说清（物体别悬空 / 别穿模 / 镜头别钻进地里）；做完让 Claude 开浏览器自查。写实人物仍是短板。

适合：空间感强的展示。

路线三

多模型混合

Claude 当导演

图片模型画角色场景 + Seedance 打底 + ElevenLabs 音效 + JS 重画。效果最炸，门槛最高：要提前备素材库 / API / 预算，让 Claude 拆分镜、写生成请求、检查结果、不合格重来。

适合：大片级项目。

延伸

专业软件

Blender / AE + MCP 或插件

Claude 当遥控器：claude.ai 直接调 Blender 做黏土动画；操作 AE 剪发布片只花 Pro 额度 5%（约 150 日元），成品回 AE 还能继续改。人的手艺不动，AI 跑腿。

适合：已有专业软件工作流的人。

云舒版三角色叫法：当画笔 = 2D / 3D，当遥控器 = 专业软件，当包工头 = 多模型混合——同一条"代码是接口"论点的三个切面。

实操清单（《咬了一口月亮》实证）

  • 起步用模板：ClaudeAnimationBase（"末日之歌"作者开源，p5.js + 手绘笔刷 + 31 个表情），让 Claude 读完 README 和动画指南再开工。
  • 两样提前备：角色设定图（各角度各姿态，或让模型手绘）、TTS 接口文档放进项目（免得最后用免费朗读声）。
  • 提示词三宝：
    1. "必须做清楚的两个瞬间"——验收标准具体到能打勾：咬一口月饼月亮同步缺一口且缺口同形状、分一半月饼月亮复圆（不是"做得唯美点"）。
    2. 先做到"月亮缺了一口"确认笑点成立，再做后半段——分阶段验收，前半段不成立不烧后半段的钱。
    3. 每个镜头渲染截图自己检查——把画看改循环写死在提示词里。
  • 提前写死的还有：观众画像（手机上看的中国读者）、规格（30—40 秒 / 1920×1080 / 24fps）、镜头间转场、给观众留看懂的时间。

8 步 SOP 精髓

核心咒语「每一帧只由时间决定」——确定性绘制的可执行版：改哪秒改哪秒、导出结果每次一样。写进需求省一大半返工。
  • 卡点别按 BPM 算——先分析真实鼓点存成表（差 0.05 秒耳朵听得出来），动画按"第几拍"写不按"第几秒"；自己作曲时让模型输出时间表，曲子就是剧本，改音乐画面自动对齐。
  • 挑剔导演自查——把每镜头截图拼成联系表，6 项打分（开头 2 秒抓人 / 手机上字清楚 / 动作顺 / 变化够多 / 构图 / 卡点准），挑最差 3 个改完再交。
  • 项目放 CLAUDE.md 规则手册——"不要渐变背景 / 要卡点"等固定要求写手册，不重复说。
  • 类型切换只换"节奏"段：卡点 MV = 鼓点节奏，宣传片 = 信息节奏（每 2—4 秒讲清一件事），故事片 = 剧情节奏。
  • 避坑：免费音乐不等于随便用（Uppbeat 免费档要署名且一码一视频，Pixabay 不强制署名）；字体加载完再截图；拼接咔哒声加淡入淡出；30fps 预览比 60fps 快近一倍。

工具落地

  • HyperFrames 补上最后一公里：HeyGen（数字人公司）开源，58696 Star，定位"Write HTML. Render video. Built for agents."——自搭摄像机环节（无头浏览器逐帧截图 + FFmpeg 拼接）它全包。
  • HeyGen 选型教训：早期试 Remotion（React 框架），发现框架限制越多、智能体产出越保守雷同，换回纯 HTML 创意才回来——给智能体留自由度，工具不是越规范越好。
  • 7 类代码工具箱：① JS + Canvas2D 平面画布 ② HTML/CSS + SVG 网页元素（产品宣传片动效）③ WebGL 着色器（独立质感层——扫描线 / 胶片颗粒 / 水面反光）④ Three.js 3D（产品 3D 模型文件可直接交给 Opus 导入做动画，电商展示对口）⑤ p5.js + p5.brush 手绘笔触 ⑥ HyperFrames / Remotion 框架类 ⑦ Manim（Python 数学动画）。
  • 确定性渲染三条军规：代码不能读当前时间、不能用没有固定种子的随机数、渲染时不能联网。守住三条，同一份代码每次渲染出完全相同的视频，多浏览器进程并行分渲才可能。
  • 15 种风格提示词全开源：皮影戏 / 等距流程 / 比例尺对比 / 白板手绘 / 汉字演变 / 3D 拆解 / 像素典故 / 绘本科普 / 数学可视化 / 地图动画 / 数据信息图 / 扁平 MG / 卡点金句 / 漫画分格 / 时间线。三大优势：字不会错、改得快、10 块 vs 视频模型几百抽卡。

五部门流水线：把自查拆成五个角色

「挑剔导演自查」的进阶版：一个人干五个角色的活，但要交出五份文件。

导演片子在说什么 → 交出 BRIEF.md
美术指导视觉规则（字体 / 配色 / 构图 / 动势）→ 交出 STYLE.md
动画师写动画代码 → 交出源码
渲染工程师导出、验分辨率帧率字体资源 → 交出 MP4 + 静帧
评论家挑毛病 → 交出 reviews/findings.md
  • 顺序不能乱：多数视觉失败发生在渲染之前——"故事不清楚，更好的动效也救不了它"。所以导演和美术指导都要先出文件、等批准，再让动画师碰代码。
  • 一个角色一个文件：会话断了、任务跑几小时，靠文件恢复现场，不靠聊天记录还活着。这是长任务能不能扛住的真分界线。
  • 美术指导不抄图，抄规则：给 2—3 个参考，每个指定一项用途（一个定字体、一个定转场、一个定节奏），让模型抽出规则写进 STYLE.md；同时写清要避免什么。光说"高端极简电影感"等于没说。
第五个角色才是真增量——评论家：① 干活的不给自己打分，要开全新上下文，只喂原始简报 + 渲染出的帧，不喂制作过程的心路 ② 渲染成功只证明文件存在，不证明东西好 ③ 缺陷写成工单五件套：帧号 / 看见什么 / 为什么重要 / 最小修法 / PRESERVE 不许动什么 ④ 修复只做局部，改完只重渲受影响帧 ⑤ 同一缺陷最多修两轮，两轮不成停下说清卡点 ⑥ 绝不许为过验收而删验收要求。

交付观：一次渲染不是一份交付物。16:9 / 1:1 / 9:16 各自重新排版、各自抽帧各自验收，禁止裁切复用。交付包 = 成片 + 封面帧 + 联系表 + 可编辑源文件 + 一页"还剩什么限制"的说明。

去 AI 味：从质感一路管到版面

代码画有个副作用——画面太规整，像 PPT。这条词条一个月里长出了三层解法，分工明确、别混用：

质感层（4.8，空格）

治"线条太干净"

  • rough.js 手绘线：端点加随机偏移，用两三条略不同的曲线叠起来，像铅笔描了两遍
  • SVG 描边生长：虚线长度设成整条路径长度，偏移从全长减到 0，线条像笔画出来
  • 水彩晕染：同一形状生成 40 多个边缘带偏移的版本，每层 4.5% 不透明度叠加——中间深、边缘浅

版面层（4.9，卡尔）

治"信息不会摆"

  • 语义色板：背景 / 正文 / 次要 / 重点 / 状态五种含义五种色，写死
  • 一屏一事：先定这屏最想让人看懂的那一件
  • 删装饰：标题上方的英文小字、每段套的框、失控的字号
  • 动效四目的：引导视线 / 展示变化 / 推进叙事 / 操作反馈，答不上就删

三层之外还有第三层：生产线层（五部门 + 评论家），治的是"人怎么组织"。三层从上到下越来越靠近"人的判断"，而不是越来越靠近"代码技巧"。

一个容易用错的地方：4.9 全是减法，但 人味与AI味 的结论是"减法死路"。两者不冲突，分界在这东西是谁写出来的——破折号、口水词是你分布的一部分，删掉=回到均值；标题上方的装饰英文、每段套的框是模型偏好的产物，删掉=回到中性而非回到平均。一句话：删装饰 ≠ 删指纹。

这三层已成体系：版面六条抽成了 html(可视化笔记)/概念馆-批量生产规范.md 的 §4.5「版面去 AI 味六查」，概念馆批量出页时与 lint 红线一起过。lint 管禁什么，§4.5 管怎么分主次，4.8 管质感。

成本账

80 分钟出 30—40 秒手绘短片（渲染约 21 分钟）；输出约 22 万 token；总量约 4400 万但 98% 是便宜的缓存读取——同一会话反复读同一坨代码和指南，缓存命中便宜十倍以上。

按 API 折算约 16.8 美元，占 Max 5x 周额度约 3%。

省钱的机制就在 上下文工程 的 KV Cache 经济学里：省钱主要省在同一会话内，任务干完再关。

桑老哥适用场景

状态修正（2026-10-08）：本词条所述路线桑老哥已在生产一线使用近月——视频工厂三系列全走 HyperFrames 线，声音时间线 / 字幕实测时长等铁律已内化成 SOP。下方起步类建议（先做小片试等）已过时；视频工厂踩坑账本（字体竞态 11 轮根治 / 渲染启动五连坑 / 气泡漂移静态抽帧验证被骗）是一手实证，比外部文章更硬，复用本词条知识时以那边为准。
  • 省钱分工：想方案 / 定审美切 Opus，批量执行丢 Sonnet 5.5（便宜一半快三成效果不打折）；这活是 Claude 家独门——CodeX 三败垫底（一个 case 用到底没合集感 / 缩放偷懒 / 配乐不卡点）。3D 也是 Opus 独门，Sonnet 只会干净执行不会"加戏"。
  • 电商直接对口：实拍素材卡节拍剪发布片；口播剪成片（实测一单 $72）；零生成模型店铺片。配套提示词法——电商宣传片给网址自动截真实界面、找真实 logo 配色，禁止凭想象画界面；多尺寸同一套时间线分开做，禁止横屏裁竖屏。
  • 产品视频字幕不再乱码：卖点字幕用代码画路线，文字就是形状，画出来就是对的。
  • 做熟的同类片打包成 skill = 「每周同类 → Skill」同构，下次口令直出。
  • 宜家手册式分步讲解可迁移到 A+ / 详情页：一张图讲一步、只讲当下这步。
  • 2D 路线最合算：B 站三系列片头动画、风格化短视频直接对口，且不用另花钱买视频模型抽卡。

前提与局限

  • 写实人物仍是短板（3D 路线人物模型需单独生成）。
  • 混合路线不是一段提示词能完成的，需提前备工具和预算。
  • 成本数字为作者自报、无第三方验证；但模板开源可查、方法论独立成立。
  • 代码画治不了"画面质感"——质感仍要视频模型或图片模型。与 AI视频提示语实战 是配对关系：那条讲给视频模型写提示语，这条讲不用视频模型。
