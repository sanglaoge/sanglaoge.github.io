AI工作流重构三步法

稳定 建条 2026-09-15 下次复核 2026-12-15

不找工具找瓶颈。拿着工具找活干是本末倒置——先定目标、画出现有流程，找到最卡的环节，只在瓶颈处上自动化。

三步演进条

目标清晰

用一句话说清要什么产出：输入结果 + 预算 → 输出交付物。

反面："用 AI 提效"这种模糊目标

找瓶颈

画出现有流程图，找到最耗时间、最易出错的环节。

反面：全流程都想自动化

瓶颈处自动化

只在那最卡的一环上 AI / Skill，其余保持原样。

反面：一把梭全自动

瓶颈图：先画图，再动手 ·核心

第一步定目标，第二步画出上面这条流程，第三步只给深色瓶颈环节接 AI——其余环节保持原样

实战案例（已在用）

案例一 · 法律审稿 Agent

Claude Agent Platform

目标 = 审合同风险 → 瓶颈 = 初筛读全文 → 只自动化初筛，终审留给人

终审这种判断环节不过度自动化，正好落在 AI与人的分工原则 上。

案例二 · 桑老哥的选品

竞品分析交给铁柱

第二步找到的瓶颈 = 查数据费时 → 让铁柱多源搜集竞品情报

同款思路的候选场景：listing 合规预审、差评分流。

跟谁咬合

不跳步：重构后的流程要过 四阶段验证框架——自动化跑得顺不顺，也要验证了才算数；约束怎么定，参考 约束先行；沉淀下来的瓶颈解法写成 skill，走 技能进化 的路径；学新流程的节奏按 飞轮学习法 转。

关联词条

四阶段验证框架重构后的流程要过验证，不跳步 AI与人的分工原则瓶颈自动化之后，判断环节仍留给人 飞轮学习法学新流程、新工具的节奏方法 约束先行给自动化定边界的前提做法 技能进化瓶颈解法沉淀成 skill 的路径
