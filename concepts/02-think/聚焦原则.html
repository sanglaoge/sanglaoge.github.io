聚焦原则

稳定 建条 2026-08-03 下次复核 2026-11-18

聚焦不只是"专注做一件事"——判断力（知道什么最关键并敢放弃其他）和压强（投入压倒性资源打穿）缺一不可。战略的核心不是选什么，是放弃什么。

判断力+ 压强= 聚焦

一句话说清楚

聚焦 = 判断力 + 压强：先靠判断力找到那个"最值得打"的城墙口，再用压倒性的资源打穿它。不是什么都做 60 分，是一个做到 95 分。

概念根："压强原则"的经典根是华为基本法 / 任正非——"千军万马只对准同一个城墙口冲锋"，已流传 20+ 年。Anthropic 的"聚焦 coding"是该原则的一个应用案例，不是概念出处。 来源文章：拆解 Anthropic（Celia）、tw93 开源产品方法论（向阳乔木），2026-05-28 沉淀

两种打法对照 ·核心

反模式

摊薄兵力

  • OpenAI 同时铺 300 个项目，被 Anthropic 田忌赛马
  • 什么都做 60 分，没有一个 95 分
  • 频繁切换赛道，复利永远为零
  • 反复纠结"该做什么"，决策消耗大
正解

压强打穿

  • Anthropic 只压 coding，连多模态都不碰
  • Costco 只做低价、Apple 只做体验——一个变量推到极致
  • tw93 的 Mole 半年迭代 40 个版本，越做越多人知道
  • 提前把事定死，不用反复纠结——长期主义的本质不是坚持，是提前定死

为什么重要

摊薄的代价被低估

兵力散在多条线，每条都打不穿。桑老哥四条线（选品 / 运营 / 共学 / IP）面临同样风险。

复利需要时间积累

频繁切换赛道，复利永远为零；守住一个口子持续迭代，时间才站在你这边。

减少决策消耗

长期主义的本质不是坚持，是提前把事定死，不用反复纠结。

怎么用

先找到最让你难受的问题

不是"我想做什么"，是"什么东西让我难受、我顺手解掉"。tw93 六款产品全部源于自身痛点。

主动设约束

GitHub 只留 6 个 pin 位、一家公司待 11 年。约束不是限制，是帮你省决策精力。

把关键变量推向极致

Anthropic 只做 coding、Costco 只做低价、Apple 只做体验。不是一个方向做到 95 分，其他碰都不碰。

记录失败比记录成功重要

别人可以蒸馏你的产品，蒸馏不了你踩过的坑。

前提与局限

  • 聚焦是高风险高回报策略——选对了赢很大，选错了浪费时间（幸存者偏差提醒）
  • 需要有判断力——判断力来自领域经验和试错，新手盲目聚焦等于赌博
  • 资源有限时聚焦是被迫的智慧；资源充足时要主动克制，更难

桑老哥适用场景

选品

不是什么品类都做，选一个最有杠杆效应的品类打穿。

个人 IP

不是什么都分享，找到一个独特角度持续输出。

AI 学习

不是什么新工具都试，先把 Claude Code 和核心 Skill 用到极致。
