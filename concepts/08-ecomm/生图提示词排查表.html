生图提示词排查表

稳定 建条 2026-08-24 下次复核 2026-11-24

一句话说清楚

提示词是交付说明不是咒语——把 AI 需要判断的东西补齐；9 个维度当排查表分层用，不是每次填满。

心法：力气花在交付，不在氛围

堆一大段风格词/镜头词/艺术家词/材质词/光影词，看起来专业，实际主体歪、构图乱、文字乱码——力气花在「氛围」没花在「交付」。给 AI 的本质是一份干活说明：这图干什么、什么最重要、什么绝不能出问题。

不是越长越好，也不是越短越高级。例外：固定品牌模板、长期复用视觉系统、已跑通工作流，长提示词合理（为维持一致性）——但那是「记忆」维度的事，不是门槛感。

9 维度排查表（速查）

#维度解决的问题
1任务这张图要完成什么目标
2输入有哪些素材、文字、参考图
3输出交付成什么比例、格式、画面类型
4约束不能出现什么错误或违规项
5上下文用在哪个平台、场景、行业
6受众谁会看到，对什么敏感
7记忆是否沿用固定风格、品牌规范
8成功标准什么样才算能用
9示例有没有参考图、对标、避坑样本

分层补全：按需加载的三级流程

= 上下文组织原则 按需加载的生图版：先轻后重，缺什么补什么。

第一级 · 一次性配图
先补 5 项
用途 / 主体 / 比例 / 风格 / 禁区
大多数图到这一级就够了
↓ 不达预期，再加码
第二级 · 结果不满意时
再补 4 项
受众 / 平台 / 成功标准 / 参考图
先排查缺哪个，别整段重写
↓ 升级为长期资产，才上第三级
第三级 · 长期视觉
才加记忆 + 示例
固定封面 / 品牌图 / 系列海报
要一致性不是抽奖；到品牌模板阶段，版式交给 Canva 这类模板工具，AI 只管底图和元素

借鉴 vs 完成：两条路别混

  • 抄别人跑通的提示词 = 找风格——攒视觉词汇：镜头语言/光线方向/色彩倾向/材质质感。写不出好看的图常不是不会写 prompt，是脑子里没有视觉输入
  • 自己写排查表 = 完成任务——实际生图场景多是「要一张头图/封面/产品图」，风格只是一层，成败在任务/输出/约束/上下文/成功标准

三件顺手工具 + 电商垂直版

工具一 · 最小可用
生图 brief 填空
我要生成一张用于【平台/用途】的图片。
画面主体是【主体】，核心动作/状态是【动作或状态】。
画面比例为【16:9 / 9:16 / 3:4 / 5:2】，构图要保证【主体清楚 / 有标题留白 / 适合信息流点击】。
整体风格参考【写实摄影 / 插画 / 3D / 手绘 / 商业海报 / 某张参考图】。
画面中【不要出现文字 / 只出现指定文字：XXX】。
请避免：乱码、错字、水印、畸形手、扭曲五官、模糊主体、多余杂物、过度复杂背景。
成品标准：一眼能看懂主题，主体清晰，能直接作为【封面/配图/海报】使用。
工具二 · 看图反推
抄结构不赏析

给参考图让 AI 反推可复用提示词：不逐像素描述、不堆形容词，保留视觉结构/主体关系/构图/光线/色彩/材质/氛围；图里有文字就说明位置与风格；输出 300 字以内 + 5 个可替换变量。= 视频生成提示词 抄作业法的图片版：抄可迁移结构，换主题只改变量。

请根据我上传的参考图，反推一份可复用的生图提示词。
要求：1. 不逐像素描述，不堆形容词
2. 保留最关键的视觉结构、主体关系、构图、光线、色彩、材质和氛围
3. 图里有文字请说明位置和风格；不适合交给生图模型的建议后期排版
4. 输出可直接复制的提示词，控制在 300 字以内
5. 补充 5 个可替换变量
输出格式：可复用提示词 / 可替换变量 / 需要避免的问题
工具三 · 改图专用（2026-09-10 增量）
修改边界法：把「不能改的」逐项列出来

来自 GPT Image 2.5 vs 即梦 5.0 Pro 三十组实测：高分改图提示词的共性不是写清「改什么」，而是把「不能改的」逐项列出来。改图时模型最容易犯的错不是没改对，是把你没让它动的东西顺手改了——产品磨砂变亮面、花纹被镜像、人物被顺便美颜。光说「改背景」等于把其余全部交给模型猜；把禁区列死，模型只剩「猜」改得像不像。

【改什么】把背景换成【新场景】，保持产品材质、颜色、光影方向不变
【锁细节】提带材质、形状与双铆钉不变；胸针保持在身体原来那一侧
【禁镜像】不得镜像花纹与文字方向
【锁其余】除指定修改部分外，画面其余所有元素保持不变

配合「约束」维度用：新图先填禁区（乱码/畸形），改图先填边界（什么不能动）。注意边界法不保证像素级——改完后仍要人工核对指定区域外的细节（实测中移除路人时书封陈列仍被动过）。

选型顺带记一笔：改图要「听话、保真」→ GPT Image 2.5；要「电影感、氛围」→ 即梦 5.0 Pro（即梦换光会顺便美颜，偏题）。

电商垂直版（2026-09-20 并入）
子母二段式模板：母锁产品，子换场景

母提示词（锁死产品，换场景不动）：产品名 + 专业商业摄影级 + 「CRITICAL: Preserve 100% of the original product design」——形状/结构/比例/颜色/材质纹理/logo 位置全忠实；这是给真实产品拍照，不是概念设计。

变量层（换市场才改）：品牌名 / 目标市场 / 界面语言 / 主图尺寸（如 2000x2000）。

写完三问验收（闭环）

问一
干什么？
问二
什么最重要？
问三
什么不能出现？

先交付说清楚，再调风格（= 目标契约与五个闸门：验收先行）。写完别问专不专业，问三句：干什么？什么最重要？什么不能出现？

小白说法与专业术语对照

小白说法专业术语
按需补全，不是每次填满分层加载（渐进式上下文）
长期视觉沿用固定风格一致性维护（记忆维度，审美规则化）
看图反推可复用结构逆向工程提示词
什么绝对不能出现负向约束（negative constraints）
改图时把不能动的逐项列出修改边界（保真约束）
给 AI 一份交付说明生图 brief

生图路

Lovart 生图先填 brief 五项 → 不达预期按分层补全加码 → 改图必带边界法四句 → 电商批量出图走子母模板。整体风格层配 DESIGN.md-给AI的视觉角色卡，单张构图选 海报构图16式——本表与构图手册一纵一横：构图管骨架，排查表管交付质检。

分工提醒

判断（这图干什么/什么最重要）留给人，执行交给 AI——见 AI对跨境电商设计师的价值边界。3D 渲染图同样过本表成功标准维度（Blender入门五概念）。
