核心洞见（总纲）

Skill 设计的总纲：触发要准（prompt-only 不执行就是最高体现）、结构要拆（复杂先拆后合）、进化要留（重复错误改规则不改结果）。

三根支柱 · 逐级抬升

支柱一

触发精准

Skill 多了以后，命不命中的语义边界比写什么更重要。prompt-only 不执行的闸门，是触发精准度的最高体现。

详见 · 目标契约与五个闸门
支柱二

结构拆合

复杂 Skill 先拆后合，走五阶段；合并太早是第一大坑——模块还没站稳就焊死，改一处崩全身。

黄叔 Skill 系列
支柱三

持续进化

技能内化负责把经验显式化，技能进化负责把重复错误写回规则——同一个错误只允许犯一次。

详见 · 技能内化 / 技能进化

一级管「叫得应」，二级管「拆得开」，三级管「越用越准」——爬到顶才算一个成熟的 Skill

外部印证一：判断模型做技能路由（2026-09-22）

支柱一（触发精准）在「skill 太多」那天会撞墙：182 个 skill 里只能选 1 个（WaytoAGI Jev 十五案例之一）。解法不是把描述写得更长，而是换一条路——先粗筛，再精读。

第一步 · 便宜粗筛

用判断模型只看 skill 描述打分，把 182 个收敛到少数候选。不读正文，所以便宜

→

第二步 · 精读胜出者

只有入选项才被完整读一遍，再决定触发谁

182

候选 skill

16.8% → 7.3%

错选率

启示 skill 多到「名字牌」被挤小时，别让大模型逐个精读全文——先便宜粗筛（只看描述打分），再精读胜出者。这与「触发精准」同向，是 less is more 的路由版；判断模型本身见 System One判断模型 应用篇。

外部印证二：模版 vs Skill 分工（2026-09-24）

卡尔 awesome-seedance（463 条 AI 视频提示语实测蒸馏，烧两万复现跑出来的）给了一句最白话的分界：

一句话分界 模版是单个镜头的配方，Skill 是整部短片的拍摄手册。模版把一段镜头参数填好、改主体场景就能用；Skill 管拆分镜 / 选模型 / 转场 / 角色一致性整套方法。
维度模版Skill
管到哪一层单个镜头：参数填好、换主体场景即用整部短片：拆分镜 / 选模型 / 转场 / 角色一致性
复用颗粒度一次一填长期反复调用
选择标准偶尔做一次 → 模版每周做同一类 → Skill

这条与支柱二「结构拆合」同向：颗粒度按复用频率定——只做一次就写死成模版，天天做的才值得拆成方法论。具体形态见 AI视频提示语实战。

写 skill 前先问一问

这个能力该是全局还是项目级？ 高频跨项目 → 全局（每个会话都交描述税，所以必须真的到处用）；专用 → 项目级（跟着项目走，不污染别家）。想清楚再落笔，比写完再搬家便宜得多。

前提与局限

  • 总纲是合成方法论（source_type: synthesized · validation: practiced），三支柱之间的优先级依任务而定，不是硬顺序。
  • 「合并太早是第一大坑」来自黄叔系列经验，量化阈值没有——拆到几块算够，靠试跑判断。
